# Atelier Arka

A production-oriented luxury interior architecture website built with Next.js, TypeScript, Tailwind CSS, Framer Motion, Lenis and Swiper-ready styling.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

## Content editing

- Company, contact and WhatsApp: `data/siteConfig.ts`
- Portfolio: `data/projects.ts`
- Team: `data/team.ts`
- Furniture: `data/furniture.ts`
- Services: `data/services.ts`
- Testimonials: `data/testimonials.ts`

Images use a combination of the original generated hero asset in `public/images/` and remote editorial placeholders. Replace remote URLs with final commissioned photography before launch.
